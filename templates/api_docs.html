MENGDRIVE S3 API DOCUMENTATION

This application provides a 100% S3-compatible REST API. You can use standard AWS SDKs (`boto3`, `@aws-sdk/client-s3`), `aws-cli`, `rclone`, or `curl` to manage files.

BUCKET OPERATIONS

DIRECTORY API
PUT /:bucket Create New Bucket
GET /:bucket List Bucket Files
DELETE /:bucket Delete Bucket

OBJECT FILE OPERATIONS

STORAGE API
PUT /:bucket/*key Upload File
GET /:bucket/*key Download File
DELETE /:bucket/*key Delete File

cURL COMMAND EXAMPLES & CODE SNIPPETS

1. Upload File via cURL (Auto-Generate Lowercase Bucket)

curl -X PUT http://localhost:3060/my-bucket/gambar.png \
  -H "Content-Type: image/png" \
  --data-binary "@gambar.png"

2. Download File via cURL

curl -o gambar.png http://localhost:3060/my-bucket/gambar.png

3. Streaming Video / Audio Direct Stream (HTTP 206)

http://localhost:3060/ui/buckets/my-bucket/stream/video.mp4
